# 🚀 Intervex AI — AI-Powered Mock Interview Platform

> Practice technical interviews with intelligent AI-driven feedback and performance analytics.


![Stack](https://img.shields.io/badge/stack-MERN-green.svg)
![AI](https://img.shields.io/badge/OpenAI-orange.svg)



## 📌 Overview

**Intervex AI** is a modern AI-powered interview preparation platform designed to help users practice technical and behavioral interviews in a realistic environment.

The platform simulates interview rounds, evaluates responses, provides AI-generated feedback, and helps users improve communication, problem-solving, and technical skills — all in one place.

---

## ✨ Features

### 🎤 AI Mock Interviews
- Real-time AI-driven interview sessions
- Technical and behavioral interview practice
- Dynamic question generation based on role & skills
- Interview timer and session management

### 📊 Performance Analytics
- AI-generated detailed feedback
- Score-based evaluation system
- Strength and weakness analysis
- Communication and clarity assessment

### 👤 User Authentication
- Secure login & signup with JWT
- Protected routes and session management
- User profile and history tracking

### 📄 Resume & Project Support
- Resume-based interview generation
- Project-focused questioning
- Automatic skills extraction
- Personalized interview experience

### 📥 Reports & PDF Export
- Downloadable interview reports
- AI feedback summaries
- Performance tracking over time
- PDF generation support
